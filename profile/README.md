# Plenipo

**Mandates, not full powers.** Verifiable mandates for AI agents, anchored to the EU Digital Identity Wallet.

A person approves a mandate in their EUDI Wallet once: what the agent may do, whom it may pay, how much,
until when. The agent attaches proof of that approval to every request, and any service can verify it
before acting. Sub-delegation can only narrow a mandate, and the person can revoke it at any time.

- Library: [plenipo-net/plenipo](https://github.com/plenipo-net/plenipo), `npm install plenipo`
- Specification and test vectors: [docs/spec.md](https://github.com/plenipo-net/plenipo/blob/main/docs/spec.md)
- Website: [plenipo.net](https://plenipo.net)

Open source under Apache 2.0. Experimental: not yet for real money or real data.
Security reports: [privately, through GitHub](https://github.com/plenipo-net/plenipo/security/advisories/new).
